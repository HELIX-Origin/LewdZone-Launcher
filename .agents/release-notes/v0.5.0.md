# LewdZone Launcher v0.5.0

**Release date:** 2026-09-25

## ✨ Highlights

Minor release moving search into the titlebar and making it context-aware, so typing in the search box always filters the page you are actually looking at, plus extending the resolver's ad and popup protection onto the third-party download host pages it opens.

## 🚀 Key Improvements & Features

- **Context-Aware Titlebar Search:** The search box now lives centered in the custom frameless titlebar instead of inside the Store page, and automatically targets whichever view is active — the Store catalog, your installed Library, or your Favorites — with per-scope placeholders ("Search store…", "Search library…", "Search favorites…"). Library and Favorites filter instantly by title with no extra network round trips, while the Store keeps its server-backed catalog query.
- **Single Search Entry Point:** Removed the redundant in-page Store search input and its styles so the titlebar field is the only search control in the app.
- **Resolver Ad Blocking on Host Pages:** The Secure Ad-Free Resolver now carries its protections through to the external download-host pages it navigates to. A shared `AD_BLOCK_SCRIPT` hides or removes common ad containers, ad and tracker `<script>` tags, and ad-network iframes; keeps enforcing via a `MutationObserver` as pages load dynamically; blocks `window.open`, `alert`, `confirm`, and `prompt`; and rewrites `_blank` links to `_self`. It is injected both when the resolver webview is created (`initialization_script`) and again after every in-app navigation via `resolver_navigate_in_app`.

## 🐛 Fixed

- **Titlebar Search Overlap:** The centered search field was absolutely positioned while the window title stayed in flex flow, causing the two to render on top of each other. The title is now hidden whenever a search scope is active.
- **Unusable Search Input:** The titlebar sets `user-select: none` and `cursor: grab` for window dragging, both of which the search field inherited — preventing text selection and editing. The field now opts out.
- **Layout Route Parse Error:** Replaced an invalid immediately-invoked function expression inside `$derived` on `/+layout.svelte`, which was breaking `svelte-check` and blocking the frontend build gate.

## ✅ Changed

- Version metadata bumped to `0.5.0` across `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, and `src-tauri/tauri.conf.json`.
- Roadmap milestones renumbered (Application Self-Updater → `v0.6.0`, Offline Catalog & Version Tracking → `v0.7.0`) to clear the `v0.5.0` collision, and a duplicated "Later" section was removed.

## 📦 Install & Upgrading

Download the installer for your platform from the Assets section below:

- Windows: `LewdZone-Setup-v0.5.0-windows-x64.exe`
- macOS: `LewdZone-Setup-v0.5.0-macos-arm64` (or `macos-x64` if available)
- Linux: `LewdZone-Setup-v0.5.0-linux-x64`

Upgrade in place: run the new installer over your existing installation. The unified installer will repair/replace files and update shortcuts.
