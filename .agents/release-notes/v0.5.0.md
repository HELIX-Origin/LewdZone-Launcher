# v0.5.0 — context-aware titlebar search + resolver host-page ad blocking

**LewdZone Launcher** · **Release date:** 2026-09-25

## ✨ Highlights

Minor release that moves search into the titlebar and makes it context-aware, so typing in the search box always filters the page you are actually looking at. Also extends the resolver's ad and popup protection beyond the in-app verification page and onto the third-party download host pages it opens.

## 🚀 Key Improvements & Features

- **Context-Aware Titlebar Search:** The search box now lives centered in the custom frameless titlebar instead of inside the Store page. It automatically targets whichever view is active — the Store catalog, your installed Library, or your Favorites — and updates its placeholder text to match ("Search store…", "Search library…", "Search favorites…"). Library and Favorites filter instantly by title with no extra network round trips, while the Store keeps using the server-backed catalog query.
- **Single Search Entry Point:** The redundant in-page Store search input and its styles were removed, so the titlebar field is now the only search control in the app.
- **Titlebar Polish:** The window title text is hidden while a search scope is active so the two cannot overlap, and the field opts out of the titlebar's drag styling (`user-select: none` / `cursor: grab`) so text can be selected and edited normally.

## 🛡️ Security & Governance

- **Ad Blocking on Download Host Pages:** The Secure Ad-Free Resolver now carries its protections through to the external hosting pages it navigates to. A shared `AD_BLOCK_SCRIPT` hides or removes common ad containers, ad and tracker `<script>` tags, and ad-network iframes; keeps enforcing via a `MutationObserver` as pages load dynamically; blocks `window.open`, `alert`, `confirm`, and `prompt`; and rewrites `_blank` links to `_self`. The script is injected both when the resolver webview is created (`initialization_script`) and again after every in-app navigation via `resolver_navigate_in_app`.
- **Host Blacklist Unchanged:** Resolver host blacklist enforcement and captcha/blacklist error surfacing were re-verified green in this release.

### 🐛 Fixed

- **Layout Route Parse Error:** Replaced an invalid immediately-invoked function expression inside `$derived` on `/+layout.svelte`, which was breaking `svelte-check` and blocking the frontend build gate.
- **Titlebar Input Usability:** The titlebar search field inherited `user-select: none` and `cursor: grab` from the frameless titlebar, which prevented selecting and editing text inside it.

### ✅ Changed

- **Version Metadata:** Bumped to `0.5.0` across `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, and `src-tauri/tauri.conf.json`.
- **Roadmap Milestones:** Renumbered the reserved milestones (Application Self-Updater → `v0.6.0`, Offline Catalog & Version Tracking → `v0.7.0`) to clear the `v0.5.0` collision, and removed a duplicated "Later" section.

## 📦 Quick Start & Upgrading

Download the installer for your platform from the Assets section below:

- Windows: `LewdZone-Setup-v0.5.0-windows-x64.exe`
- macOS: `LewdZone-Setup-v0.5.0-macos-arm64` (or `macos-x64` if available)
- Linux: `LewdZone-Setup-v0.5.0-linux-x64`

Upgrade in place: run the new installer over your existing installation. The unified installer will repair/replace files and update shortcuts.
